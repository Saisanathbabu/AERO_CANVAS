# AERO_CANVAS

Overview:
************************************************************************************************************

Air Canvas is an advanced deep learning-based application that allows users to write or draw in the air using hand gestures. The system captures the movement using a camera, processes it using computer vision techniques, and converts the drawn matter into a document format. This project integrates TensorFlow, OpenCV, OCR techniques to enhance accuracy.
__________________________________________________________________________________________________________________________________________
Features:
*************************************************************************************************************

-->Real-time hand gesture tracking

-->Writing or drawing in the air without physical contact
-->Conversion of air-drawn text into a document format
-->Multi-color drawing support
-->Save drawings as images or PDFs
-->Interactive UI for an enhanced user experience.
____________________________________________________________________________________________________________________________________________
Prerequisites:
*************************************************************************************************************

Before running this project, ensure you have the following installed:
Python 3.x

OpenCV (cv2)

NumPy

TensorFlow/Keras

MediaPipe

PyAutoGUI (for capturing screen and saving as PDF)

Pillow (PIL) (for image processing)

FPDF (for PDF generation)
